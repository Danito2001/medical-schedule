# Medical Schedule (Tipo IntegraMedica)

## Tech Stack
- React / Next.js
- TypeScript
- Redux Toolkit
- Axios
- Tailwind CSS
- Node.js (Backend API)
- PostgreSQL / Prisma (si aplica)

## Features
- Book medical appointments using RUT and insurance validation (backend)
- Confirm or cancel appointments
- Receive email notifications with:
    - Confirmation code
    - Doctor information
    - Specialty details
- Search appointments by:
    - Specialty
    - Medical center
    - Doctor
    - Date and available time slots
- Secure login (email + hashed password)
- Dashboard to configure availability:
    - Working days
    - Time ranges per day
    - Basic validation for schedule rules
View upcoming appointments
Access patient appointment history
